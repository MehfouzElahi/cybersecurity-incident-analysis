# Cybersecurity Incident Analysis

## Overview

This project is based on a simulated cybersecurity incident analysis training exercise completed through Deloitte Australia Cyber Job Simulation on Forage.

The project focuses on analyzing simulated web activity logs, identifying suspicious user behavior, and understanding basic incident response processes.

## Objectives

- Analyze simulated web activity logs
- Identify suspicious user behavior
- Investigate potential cybersecurity threats
- Understand incident analysis and threat detection
- Apply basic incident response concepts

## Skills Demonstrated

- Cybersecurity Incident Analysis
- Threat Detection
- Log Analysis
- Security Monitoring
- Incident Response
- Suspicious Activity Identification
- Security Investigation

## Project Context

This is a training and simulation project. The data and incidents analyzed are simulated and were used for educational purposes.

## Learning Outcome

Through this project, I gained practical exposure to cybersecurity investigation, threat detection, log analysis, and basic security incident-handling processes.
